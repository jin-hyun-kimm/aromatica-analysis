# 아로마티카 현황분석 기초보고서 — 분석자료

통계컨설팅의 이해 · 중간고사 과제 · 3조 · 대상기업 아로마티카(주)

> 이 저장소는 대시보드 공개와 분석 재현을 위한 것이라 제출자 성명·학번을 넣지 않았다.
> 보고서 PDF(표지에 성명·학번 기재)는 `.gitignore`로 제외되어 있으며 담당 교수께 메일로만 제출한다.

**분석 질문** — 아로마티카의 2023~2025년 이익 개선은 영업 성과에서 나온 것인가, 재무구조 변화에서 나온 것인가?

## 1. 재현 방법

Python 3.9 이상이면 됩니다. 외부 패키지는 그래프 생성과 보고서 생성에만 필요하고,
데이터 검증과 지표 계산은 표준 라이브러리만으로 실행됩니다.

```bash
pip install matplotlib python-docx     # 03, 04 단계에만 필요

python3 code/01_verify.py              # 핵심 수치 검증 62건 (교차검증 54 + 도출값 재현 8)
python3 code/02_metrics.py             # 지표 계산 → metrics.csv, metrics.json
python3 code/03_charts.py              # 그림 1~3 → figures/
python3 code/04_build_report.py        # 보고서 → .docx
python3 code/05_build_dashboard.py     # 대시보드 → index.html
```

`01_verify.py`는 전 건 일치 시 0, 불일치가 있으면 1을 반환합니다.
`04_build_report.py`는 표지의 학번·이름을 `identity.json`에서 읽습니다. 이 파일은 공개 저장소에
올리지 않으므로, 저장소를 클론해 실행하면 `identity.example.json`의 자리표시자로 표지가 만들어지고
나머지 내용과 수치는 동일하게 재생성됩니다. 제출 ZIP에는 `identity.json`이 포함되어 있어 제출본과
완전히 같은 보고서가 나옵니다.

### 수치가 어긋나지 않는 구조

보고서 본문·표·그래프와 대시보드의 **재무 수치와 계산 지표**는 모두 `02_metrics.py`가 만든
`metrics.json`과 `data/*.csv`에서 런타임에 읽어 삽입합니다. `03_charts.py`·`04_build_report.py`·
`05_build_dashboard.py`에는 이 수치들이 문자열로 박혀 있지 않으므로 본문과 그래프의 숫자가 서로
달라질 수 없고, 원자료를 고치면 네 단계를 다시 실행하는 것만으로 보고서 전체가 갱신됩니다.
퍼센트포인트 차이도 표시값이 아닌 원수치로 계산합니다.

예외는 사업보고서 **서술문에서 인용한 산업 통계**(수출 대상국 수, 국가별 수출액, 지적재산권 건수 등)로,
계산에 쓰이지 않고 부록 G의 서술에만 등장하므로 본문에 직접 적고 출처를 함께 밝혔습니다.
그중 표로 정리한 시장 규모·성장률은 `data/industry_market.csv`에서 읽습니다.

## 2. 자료 출처

모든 수치는 DART 전자공시시스템(dart.fss.or.kr)에 제출된 공시서류 **원문**에서 직접 확인했습니다.
언론 보도, 기업정보 사이트, 증권사 자료는 수치·사실·날짜 어느 항목에도 사용하지 않았습니다.
원문에서 확인되지 않은 항목은 보고서에 포함하지 않았습니다.
한 가지 예외는 보고서 부록 G의 산업 시장 규모 전망치입니다. 이는 사업보고서가 외부 조사기관(GWI,
킹스 리서치, 포춘 비즈니스 인사이트, Statista)을 인용한 수치로, 사업보고서 원문에 기재된 값을 그대로
옮겼을 뿐 원자료를 직접 확인하지는 못했습니다. 그래서 본문의 판단 근거로는 사용하지 않았고, 그 사실을
부록 G와 보고서 5-2절에 명시했습니다.

| 공시서류 | 접수번호 | 접수일 | 사용 항목 |
|---|---|---|---|
| 2025 사업보고서 | 20260320001362 | 2026.03.20 | 2023~2025 손익·재무상태·현금흐름, 사업부문별 매출, 수출·내수 및 채널별 매출, 산업 환경 |
| 2024 감사보고서 | 20250331002452 | 2025.03.31 | 금융원가 내역, 회계기준 전환 차이조정(주석 36) |
| 2023 감사보고서 | 20240401001486 | 2024.04.01 | 과거회계기준 2023년 손익계산서·재무상태표 |
| 2026 반기보고서 | 20260818000129 | 2026.08.18 | 2026년 연결 실적, 연결대상 종속회사 현황 |
| 증권발행실적보고서 | 20251121000203 | 2025.11.21 | 공모 주식수·발행총액·일정 |

원문 링크: `https://dart.fss.or.kr/dsaf001/main.do?rcpNo={접수번호}`

데이터 파일별 출처와 DART 원문 내 위치는 `data/sources.csv`에 정리되어 있습니다.

## 3. 자료 정리 기준

- **재무제표 기준** — 2023~2025년은 별도(개별)재무제표. 아로마티카는 해당 기간에 연결재무제표를 작성하지
  않으며, 2025 사업보고서 「III-2. 연결재무제표」는 "해당사항이 없습니다"로 기재되어 있습니다.
  종속회사 AROMATICA USA INC.가 2026년 2월 4일 설립되어 2026년부터 연결재무제표가 작성됩니다.
- **회계기준** — 전 기간 한국채택국제회계기준(K-IFRS)으로 통일. 아로마티카는 2024 회계연도부터
  K-IFRS를 최초 적용했고 그 이전은 일반기업회계기준으로 작성되어, 2023년 수치가 두 기준으로 모두
  공시되어 있습니다. 본 저장소의 2023년 K-IFRS 수치는 **2025 사업보고서의 제23기 비교표시 열**에서
  가져왔고, 전환에 따른 조정 내역은 **2024 감사보고서 주석 36**에서 확인했습니다. 과거회계기준 수치는
  **2023 감사보고서**에서 가져왔습니다. 세 출처의 데이터셋별 귀속은 `data/sources.csv`에 있습니다.
  두 기준의 대조는 `data/basis_2023_comparison.csv`와 보고서 부록 E에 있습니다.
- **단위** — 원문 단위는 원. 사업부문별 매출과 금융원가 주석은 원문이 각각 백만원·천원 단위이며,
  해당 파일의 `source_unit` 열에 표기했습니다.
- **결측치** — 임의로 생성하지 않았습니다. 자본총계가 음수인 2023년 부채비율과 전년이 순손실인
  2024년 당기순이익 증감률은 해석이 성립하지 않아 `None`으로 두고 보고서에서 공란 처리했습니다.

### 산식

```
영업이익률    = 영업이익 ÷ 매출액 × 100
당기순이익률  = 당기순이익 ÷ 매출액 × 100
금융원가율    = 금융원가 ÷ 매출액 × 100
부채비율      = 부채총계 ÷ 자본총계 × 100
OCF 배수      = 영업활동현금흐름 ÷ (영업이익 또는 당기순이익)
증감률        = (당기 값 ÷ 전기 값 − 1) × 100
기여도        = 항목별 변화분 ÷ 당기순이익 변화 총액 × 100
비중          = 구성 항목 매출 ÷ 해당 연도 매출액 × 100
```

분모·단위·기준 기간을 포함한 전체 정의는 보고서 표 2에 있습니다.

## 5. 검증

`01_verify.py`는 62건을 기록합니다. 외부 자료와의 대조는 사용하지 않고, DART 원문 내부의
관계식 재계산(51건)과 같은 수치의 전사 일치 확인(3건)으로만 수행합니다.

나머지 8건(`7-*`, `7g-2026Q1`)은 성격이 다릅니다. 2026년 1분기는 원문에 직접 실려 있지 않아
반기 누적에서 2분기를 차감해 만든 값이므로, 그 항목들의 검증은 구조상 실패할 수 없습니다.
도출 과정을 남기는 기록으로서의 가치는 있지만 교차검증은 아니므로 `kind` 열에
`도출값 재현`으로 따로 표시했습니다. **원문 수치 간 교차검증은 54건입니다.**

| 유형 | 건수 | 내용 |
|---|---|---|
| 손익계산서 내부 정합성 | 12 | 매출총이익·영업이익·법인세차감전순이익·당기순이익의 관계식 |
| 재무상태표 항등식 | 3 | 부채총계 + 자본총계 = 자산총계 |
| 주석 ↔ 본문 대조 | 4 | 금융원가 내역 합계, 매출 구성 합계 |
| 사업부문 ↔ 본문 대조 | 3 | 사업부문별 매출 합계 = 매출액 |
| 과거회계기준 정합성 | 3 | 2023 감사보고서 손익·재무상태표 |
| 전사 일치 확인 | 3 | 비교표의 K-IFRS 열 = 본 데이터셋 (같은 원문 위치) |
| 2026년 분기 정합성 | 3 | 매출총이익 항등식 (2025 상반기·2026 2분기·2026 상반기) |
| 2026년 1분기 도출값 재현 | 8 | 1분기 = 반기 누적 − 2분기 (7개 항목) + 1분기 매출총이익 항등식 — 교차검증 아님 |
| 주석 간 교차 검증 | 5 | 파생금융부채 변동 ↔ 잔액, 손실충당금 증가분 ↔ 손상차손, 잔액 합계 ↔ 전환 조정액, 조정 합계 ↔ K-IFRS 당기순손익 |
| 수출·내수 및 채널 정합성 | 18 | 부문별 수출+내수 = 부문 소계, 수출·내수 합계행 = 매출액, 채널별 합계 = 매출액, 해외·국내 채널 합계 = 수출·내수 합계 |

각 검증 항목에는 원문 위치(공시서류·주석 번호)가 `source_location` 열로 기록되어 있습니다.
단위가 천원·백만원인 주석과 대조하는 항목은 그 단위만큼의 허용 오차를 두었고,
허용치와 실제 차이를 `tolerance`·`diff` 열에 기록했습니다. 매출실적표는 원문이 셀별로 백만원 단위에서
반올림되어 있어 합계가 구성 항목의 산술합과 1백만원 어긋나는 칸이 있습니다(2024년 헤어&스칼프 소계,
2024년 수출 합계). 보고서와 데이터셋은 원문에 인쇄된 합계값을 그대로 쓰고, 검증에서는 1백만원의
허용 오차를 두었습니다.

## 7. AI 활용

분석·시각화·문서 작성에 AI를 활용했습니다. AI가 생성한 사실과 수치는 모두 DART 원문 또는
재계산으로 확인했고, 확인되지 않은 항목은 보고서에 포함하지 않았습니다.
대표 프롬프트와 검토·수정 내용은 보고서 부록 B에 있습니다.
